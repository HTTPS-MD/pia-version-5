Version 5 additional files
==========================
Files that the running PIA system does not need. Nothing here is published to the website (the Cloudflare build copies
only index.html, admin, student, teacher, assets and styles), and nothing in the code refers to this folder.

docs/            notes, checklists, revision list, flowcharts (png and svg), staging test report.
unused images/   images no page uses: the three pia-hero-*.png backgrounds and the tutor .gif files
                 (the site uses the .webp files of each tutor and their -still.webp versions).

Kept in the project folder on purpose, because the tools look for them there:
  supabase/    the database SQL files and the Edge Functions (supabase CLI deploys from here)
  ml-service/  the learning-profile Worker (wrangler deploys from here)
  config/, build.sh, index.html, admin, student, teacher, assets, styles   the website itself

ml-service generated by tools/   .venv, .venv-workers, python_modules and .wrangler moved out of ml-service/. The tools (uv, pywrangler,
                                 wrangler) make them again by themselves the next time you run `pywrangler dev` or `deploy` in ml-service/,
                                 so they are safe to delete. Nothing deployed depends on them.
